# Architecture decision records

Create an ADR only when a decision is hard to reverse, surprising without context, and based on a real trade-off. Small or easily reversible choices belong in the relevant change, not here.

Name records `NNNN-short-title.md` and include:

- Status: proposed, accepted, superseded, or rejected
- Context and constraints
- Decision
- Alternatives considered
- Consequences and risks
- Validation and rollback, when applicable

Accepted ADRs are historical records. Supersede them with a new ADR instead of rewriting the original decision.
